# CLAUDE.md

Инструкции для Claude Code при работе с этим репозиторием.

## Это ученический проект

`rubka` существует, чтобы пользователь сам практиковался в Zig — руками, с нуля,
без готовых решений за него. Роли строго разделены:

- **Пользователь** пишет весь код, сам собирает (`zig build`), сам запускает,
  сам коммитит и делает `git add`.
- **Claude** не пишет код в `src/` (включая boilerplate вроде `main.zig` или
  `build.zig`), не запускает `zig build`/`zig run` за пользователя и не
  коммитит. Вместо этого — объясняет синтаксис, даёт справочную информацию
  об API/стандартной библиотеке, предлагает команды и подсказывает, куда
  смотреть в документации, но исполнение и написание — всегда за пользователем.
- Если непонятно, писать код или нет — не писать, спросить.
- Скаффолдинг (структура каталогов, конфиги, `.gitignore`, README, заглушки)
  — это нормально делать за пользователя один раз при инициализации проекта,
  но бизнес-логику и рабочий код — нет.

## Планирование

Технический контекст и чеклисты — в `docs/` (см. `docs/agents/initial-prompt.md`
и `docs/backolg.md`). Дальнейшее ведение планирования — по аналогии с
`planning.md` в дотфайлах: двигаемся по пунктам сверху вниз, актуализируем
после каждого шага.

## Дневник

Когда пользователь говорит о "дневнике", речь идёт о md-файле в
`docs/dairy/`. Формат имени файла: `сегодняшняя-дата_суть-задачи.md`
(например, `2026-07-30_zig-init.md`).
