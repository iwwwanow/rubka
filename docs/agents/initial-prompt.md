Инициализируй проект `rubka` в этом (уже созданном) репозитории.

## Что это за проект

`rubka` — инструмент широкого профиля для управления UI на Wayland/Sway: окна, раскладки, скриншоты. Долгосрочная цель — не одна утилита, а набор инструментов вокруг темы "что происходит на экране и как этим управлять". Но это ученический проект: весь код на Zig я пишу сам руками, чтобы попрактиковаться в языке и низкоуровневых вещах (сокеты, бинарные протоколы, ручной парсинг JSON). Твоя задача сейчас — только разложить скелет проекта, НЕ писать логику окна/IPC-клиента за меня. Ни строчки бизнес-логики в src/ — только структура, конфиги, документация.

## Скоуп (по приоритету, стартуем с первого пункта)

1. **Window management (Sway/i3 IPC)** — стартовая точка. Переписываю существующие bash+jq скрипты управления окнами в Sway (сейчас живут в дотфайлах `.config/sway/scripts/`: master-stack layout типа hyprland (master + stack), переключение/перенос окон между workspace) на нативный Zig-бинарник с прямым i3 IPC-протоколом через Unix-сокет (`std.net` + `std.json`, без сторонних зависимостей). Протокол: magic-строка + 4-байтная длина payload + 4-байтный тип сообщения + JSON payload. Нужны: `get_tree`, `subscribe` на события (window::new/focus/close), произвольные команды.
2. **Screenshot manager** — область экрана/окна, вывод в файл/буфер обмена. Пока не начато, только зарезервировать место в структуре.
3. **UI/window manager вообще** — более широкая заявка на будущее (не только Sway, возможно свои примитивы поверх wlroots или похожее). Не проектировать сейчас конкретно, просто оставить в README как заявленное направление, не как код.
