# Zig Handbook

Справочник по языку и тулингу для проекта `rubka`. Установленная версия: **0.16.0**
(`zig version`) — свежая, многие туториалы в сети писаны под 0.11–0.13 и не
совпадают дословно (например, сигнатура `main`, `std.Io`, модульная система
сборки). Ориентир — `zig init`, `zig build --help` и `std.` в своей версии.

## О языке

- Системный язык: ручное управление памятью, без сборщика мусора.
- Никакого скрытого control flow — нет исключений, нет перегрузки операторов,
  нет скрытых аллокаций.
- Ошибки — через error union (`!T`) и `try`/`catch`, всегда явно в сигнатуре.
- `comptime` — выполнение кода на этапе компиляции; заменяет генерики/шаблоны.
- Debug-сборка проверяет границы массивов, use-after-free, integer overflow.
- Система сборки (`build.zig`) — обычный Zig-код, строящий граф задач, а не DSL.
- Кросс-компиляция встроена, без внешних тулчейнов.
- Для IPC-части проекта релевантны `std.net` (Unix-сокеты) и `std.json`.

## Команды

| Команда | Что делает |
|---|---|
| `zig version` | версия установленного компилятора |
| `zig init` | скаффолдинг проекта: `build.zig`, `build.zig.zon`, `src/main.zig` |
| `zig build` | сборка по `build.zig`, результат в `zig-out/` |
| `zig build run` | собрать и сразу выполнить run-step |
| `zig build test` | прогнать `test` блоки |
| `zig build --help` | список шагов/опций, объявленных в `build.zig` |
| `zig build -Dtarget=<triple>` | кросс-компиляция под другую платформу |
| `zig build -Doptimize=ReleaseFast\|ReleaseSafe\|ReleaseSmall` | режим оптимизации (по умолчанию Debug) |
| `zig run src/main.zig` | скомпилировать и запустить один файл без `build.zig` |
| `zig fmt <path>` | форматирование кода |
| `zig fetch --save <url>` | добавить зависимость в `build.zig.zon` |
| `zig env` | пути компилятора, std, кэша |
