# Глобальный хоткей для перезагрузки конфигов

Фича: глобальный хоткей для перезагрузки конфигов всего софта. Сейчас
каждый инструмент перезагружается отдельно: sway через $mod+Shift+c,
waybar вручную, nvim через :source, zsh через exec zsh и т.д. Один хоткей
(например $mod+Shift+r), который перезапускает всё разом.

Acceptance criteria:

- один биндинг в sway перезагружает: sway, waybar, опционально
  zellij-конфиг
- nvim-инстансы получают reload через --server/сокет, если доступны
- notify-send с результатом — что именно перезагрузилось и что упало
- отдельный скрипт reload-configs.sh, вызываемый и вручную из терминала
