# Баги текущей bash-версии master-stack-resize

Баги текущей bash-версии (`master-stack-resize.sh` в dotfiles) — переносить логику в rubka с починкой, не 1:1:

- можно засплиттить уже горизонтальное окно ещё раз (двойной сплит)
- при перемещении окон вылезают кривости
- неровности высот в стеке остаются, несмотря на equalize_stack
