# Версионирование i3-ipc протокола

Долгий ящик, не сейчас. Отдельного номера версии протокола нет, привязано
к версии sway. Если когда-нибудь захочется подстраховаться от рассинхрона
(обновил sway — rubka отвалилась) — запросить `GET_VERSION` при старте
адаптера и сверить с диапазоном протестированных версий. Сейчас не делать:
базовый набор message types не менялся годами, риск чисто теоретический
для личного инструмента на одной машине.
